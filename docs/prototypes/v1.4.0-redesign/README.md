## 终稿(v4)包含什么

- **`tokens.css`** — 单一设计 token 源:10 套主题(`paper` 宣 / `dawn` 曦 / `latte` 瓷 / `sumi` 墨(默认)/ `mocha` 檀 / `moon` 霄 / `nord` 峡 / `forest` 苔 / `clay` 陶 / `rose` 黛)+ 字阶 / 圆角 / 间距。**实施时以此文件为 token 权威来源**(GUI 直接消费;TUI 做 256 色近似映射)。
- **`gui.html`** — 七视图单页稿:欢迎首页 · 会话(指标 5 形态)· 设置(8 组,含「状态显示」)· 改动 diff · 项目管理 · MCP 服务(概念预览)· 插件(概念预览);侧栏 = 功能区(固定)+ 项目分区(每项目独立、内挂会话)+ 独立对话。
- **`tui.html`** — 四屏终端模拟:启动首页(居中构图 / 74ch 限宽)· 会话流 · `/theme` · `/shell`。
- **`gallery.html`** — 10 主题并排画廊。
